# 中国事变系统：第一版技术说明

## 动态战况图

HOI4 1.19 的 `decision_category` scripted GUI 可以按 State 控制情况切换 GUI 元素，但没有公开脚本接口把“任意国家的动态旗帜”作为一张共享纹理，再由几十个 State 同时充当可变遮罩。`maskedShieldType` 的国家旗帜注入由原版硬编码界面负责，scripted GUI 无法为每个 State 指定任意国家。

本系统采用可验证的近似方案：

- 从原版 `map/provinces.bmp`、`definition.csv` 与 `history/states` 生成全部中、共及西藏核心 State 的精确轮廓。
- 地图没有独立背景图片；中国轮廓以外完全透明。
- 每个 State 图层只保存自身紧裁剪区域，降低纹理内存占用。
- 旗帜与 State Mask 以 940×520 双倍分辨率生成，再由 GUI 以 0.5 倍显示；最终布局尺寸不变，但旗帜徽记与边界经过超采样后更清晰。
- State 边界使用独立透明图层并始终绘制在全部旗帜之上，因此灰色区和各方控制区都会保留清晰分界线。
- 各 State 对同一幅整图尺寸的大型旗帜进行同坐标采样，因此相邻 State 显示的是连续大旗，而不是一 State 一面小旗。
- 控制国属于阵营时，优先显示阵营领袖旗帜。满洲国、蒙疆等处于日本阵营时因此显示日本旭日军旗。
- `CHI` 本人或以 `CHI` 为阵营领袖时使用抗战时期的国民革命军陆军旗，而非普通中华民国国旗。
- 旭日军旗与国民革命军军旗只做克制的明度微调：对比度约 -8%、亮度约 -3%，不改变色相或单独降低饱和度；中立石板灰区域亮度约 -12%。
- 控制国没有阵营但正在与日本交战时，显示其自己的国家旗帜。
- 预置中国各政权及德、意、苏、英、美、法等常见外部阵营领袖旗帜；非预置的特殊阵营领袖受引擎接口限制回退为灰色。
- 既不属于日本交战阵营、也没有直接对日作战的第三方保持灰色。
- GUI 打开时直接读取 State 控制者及其阵营关系，无需每日事件扫描。主要中国交战方事件目标仍仅在开战与每月钩子更新，用于谈判等事件逻辑，与地图着色无关。

运行 `tools/generate_china_incident_map.ps1` 后再运行 `tools/generate_china_incident_gui.ps1`，可基于当前 1.19 游戏地图重新生成全部地图资产和 GUI 图层。

## 公共接口

- 路线与战争条件集中在 `common/scripted_triggers/JAP_china_incident_triggers.txt`。
- 状态刷新、占领代价和资源项目集中在 `common/scripted_effects/JAP_china_incident_effects.txt`。
- 后续国策只需设置额外变量、旗标或调用公共 effect，不应复制整套决议条件。

## 性能约束

- 无每日中国 State 扫描。
- 旗帜显示由 scripted GUI 在界面刷新时直接判断。
- 仅以 `on_monthly_JAP` 更新战争月份、主要中国交战方和低概率占领事件。
- 南京首次陷落通过 `on_state_control_changed` 精确捕获；月度检查只作为提前攻占南京的补偿路径。
